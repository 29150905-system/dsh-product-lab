# PRODUCT.md · 景明（教师工作台）

> 版本：v0.2（2026-11-01）
> 阶段：课程作品 1 · 12 周冲刺

---

## 一句话定位

**我帮高中班主任，把「考完试整理学情、逐个家长沟通」从 2 小时翻表格想措辞，变成导入成绩后 10 分钟生成全班学生的学情档案和可编辑的家长沟通话术。**

品牌主张（长期）：**不替老师写教案，帮老师更快成熟。**

名字由来：景明，取自「春和景明」——愿老师的日常也晴朗一点。

---

## 目标用户

- **主要**：高中 **班主任**（跨学科看全班成绩，需要频繁家校沟通）
- **次要**：高中任课老师（只看本科目成绩，同样需要向家长反馈）
- 学段：v1 聚焦高中（数据模型保留「初中/高中」字段，后续可扩）

---

## 问题

1. 考完试后，老师要翻成绩单、逐个学生想「怎么说」
2. 家长想知道的不只是分数，而是「孩子哪里好、哪里弱、接下来怎么办」
3. 这些内容每次都要重写，耗时且情绪消耗大
4. 老师自己的成长（课堂设计能力）缺少可复用记录

---

## 产品形态：一个 App，三个模块

```
景明 · 教师工作台
├── 课堂记录      （提问点名 / 每堂课记录）        → v1.5 已上线（2026-11-06）
├── 出勤表        （点学生 = 缺勤，默认全到）      → v1.5 已上线（2026-11-06）
├── 学情与沟通    （成绩 → 学情档案 → 家长话术）  → v1 核心
└── 教师成长      （课程设计建议 / 教研笔记）      → v2
```

**v1 只做「学情与沟通」这一个闭环**，但 App 的外壳（导航、班级、学生）一次搭好，后面两个模块直接长在同一个数据骨架上。

> 为什么不一上来三个都做：12 周内三个模块 = 三个半成品。先把「输入成绩 → 输出可用的沟通内容」跑通，再扩。

## v1 用户流程

1. **建班级** → 班级名（高中默认）
2. **加学生** → 手动输入 / 粘贴名单
3. **录成绩** → 新建一次考试（名称、日期、总分），逐个填分 / 粘贴整列
4. **生成学情档案** → 每个学生：本次表现、优势、薄弱点、下一步建议
5. **生成家长沟通话术** → 每个学生一条，可编辑、可复制
6. **本地保存 / 导出** → 数据只存在本机

## v1 功能清单

- [ ] 班级与学生名单管理
- [ ] 考试成绩录入（手动 + 粘贴，v1 只录总分）
- [ ] 学情档案生成（LLM，按学生逐个）

- [ ] 本地持久化（localStorage / IndexedDB）
- [ ] 首次使用示例数据（假数据，方便体验）

## 数据模型（v1）

```
Class      { id, name, stage: 'junior' | 'senior', grade }
Student    { id, classId, name, note? }
Assessment { id, classId, name, date, subject?, fullScore }
Score      { assessmentId, studentId, value }
Profile    { studentId, assessmentId, text, createdAt }
Message    { studentId, assessmentId, text, editedAt }
Report     { assessmentId, headline, pace: '加快'|'维持'|'减缓', diagnosis, actions[], updatedAt }
Lesson     { id, classId, date, period, subject?, note?, createdAt, updatedAt }
Call       { id, lessonId, studentId, result: 'good'|'ok'|'poor', createdAt }
Sheet      { id, classId, date, period, note?, createdAt, updatedAt }
Mark       { sheetId, studentId, absent: true, updatedAt }   // 只存缺勤，默认全到
```

v1 全部存本地；导出 JSON 备份。

## 隐私与合规（红线）

- 学生数据默认**只存本地**，不上传服务器
- **点名、课堂记录与出勤表也只存本地**，不调用模型、不上传
- 调用模型前**姓名匿名化**（张三 → 学生 A），只发送成绩与匿名特征
- 演示 / 公开作品集一律用**假数据**
- 不生成公开排名，不做学生画像对外分享
- 未来做多用户/云端时，再补用户协议与监护人同意流程

## 成功指标（用来验证 v1 是否成立）

- 老师从「拿到成绩」到「发完 N 个家长」的时间：**2 小时 → 20 分钟以内**
- 生成的学情档案，老师**愿意直接改 3 处以内**就发出去
- 老师看完「班级总体学情」，能一句话说出**这周先补什么 / 要不要赶进度**
- 一节课点 8–10 人，不用动笔：抽人 + 记结果 ≤ 3 秒/人，覆盖情况一眼可见
- 出勤表 10 秒内点完（默认全到，只点缺勤的学生）
- 找 3–5 位高中班主任试用，至少 3 位说「下次还会用」
