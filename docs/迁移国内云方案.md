> 目标：国内访问稳定 + 能办 ICP/APP 备案 + 成本可控（验证期 10–50 位老师）
> 现状：Next.js 16（App Router / API Route / PWA）；学生数据存浏览器本地；同步码用 Redis

---

## 0. 一句话建议

**验证期先别迁**；要迁就选「**轻量应用服务器 2核2G + Docker + Nginx**」：
首年约 ¥200–600（新用户促销），续费约 ¥700–1,300/年（含域名，ICP/APP 备案免费）。
不要一上来买 ECS / SAE / 数据库。

## 2. 推荐架构

```
老师手机 / PWA / Android APK
        │ HTTPS（域名 + 免费证书）
        ▼
   Nginx（轻量服务器，443 → 127.0.0.1:3000）
        │
   Next.js standalone（Docker 容器）
        ├── 页面 / PWA 静态资源
        ├── /api/profile、/api/paper-analysis → api.deepseek.com
        └── /api/sync → Redis（compose 内置）
```

要点：
- 学生成绩仍然只存浏览器 localStorage，服务器不存；迁移不增加隐私风险
- 同步码依赖 Redis：`docker-compose.yml` 内置 `redis:7-alpine`，不用买云 Redis
- OCR 目前从 jsDelivr CDN 加载 Tesseract.js，国内可能慢；迁移服务器不解决，后续可自托管

## 4. 迁移步骤（1–2 天技术 + 2–4 周备案并行）

1. `next.config.ts` 已配置：Vercel 用默认，自托管输出 standalone
2. 本地 / CI 构建镜像（不要在 2G 服务器上 `next build`，容易 OOM）
3. 买轻量服务器（2C2G 3M）+ 域名实名
4. 装 Docker + Nginx + Certbot，按 `deploy/README.md` 操作
5. 配 ACR 与 GitHub Secrets，Actions 自动构建推送
6. 服务器 `docker compose pull && up -d`
7. 域名解析 → HTTPS 证书 → 验证 PWA/APK/接口
8. 旧 Vercel 保留 1–2 周做回滚

**备案并行**：
- ICP 备案：2–4 周（境内服务器必须；备案期间域名不能对外服务，继续用 Vercel）
- 公安联网备案：下号后 30 天内
- APP 备案：2–4 周（上商店才需要，免费）
- 软著：30–60 个工作日（国内安卓商店才需要，最早启动）

## 6. 什么时候真的该迁

出现任意一条再迁：
- [ ] 老师反馈国内打开慢/打不开
- [ ] 要上国内安卓商店（APP备案 + 软著）
- [ ] 要上苹果中国区 App Store（需备案号）
- [ ] 学校采购要求备案/发票/等保

否则：Vercel + APK 侧载 + iPhone PWA 是 0 成本方案。

## 7. 迁移后必做

1. 改 `mobile/capacitor.config.json` 的 `server.url` 为新域名，重新构建 APK

3. 更新隐私政策里的域名
4. 观察 1–2 周再关 Vercel
